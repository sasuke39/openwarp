# 1:1 视觉契约

## 固定几何

| 区域 | 基准值 |
|---|---:|
| 画布 | 1600×1000 |
| 顶栏高度 | 42 |
| 左栏宽度 | 248 |
| 输入区高度 | 210 |
| 输入区左右外边距 | 20 |
| 时间线最大宽度 | 1120 |
| 时间线水平内边距 | 38 |

其余尺寸从基线 HTML 提取，不允许在组件内散落魔法数字；建立 `UnifiedInputVisualTokens`，再映射到 Warp 主题语义色。

## 颜色与字体

- 背景 `#202326`，侧栏 `#25292c`，顶栏 `#1c1f21`。
- 输入表面 `#222629`，分隔线 `#383d41/#303438`。
- 主文字 `#d7dade`，次文字 `#b9bec2`，弱文字 `#858c92`。
- Agent 紫 `#c586c7`，成功绿 `#61c889`，用户蓝 `#75a9c9`。
- 中文/正文使用系统 UI 字体；命令、路径、耗时使用现有 Warp 等宽字体。
- 原型优先于自动设计系统建议：禁止 OLED 纯黑、霓虹、发光和外部 Web 字体。

## 组件表现

- 使用平面表面、1px 分隔线、3–4px 小圆角；无阴影和渐变。
- Terminal 与 Agent 状态同时使用图标和文字，不能只靠颜色。
- 模式、排队、Steer、失败和取消均有明确文案。
- 可点击区域有 hover、pressed、disabled 和键盘 focus 状态，不改变布局尺寸。
- 异步操作超过 300ms 显示进度；提交中禁止重复点击。

## 像素验收

- 使用确定性 fixture、同一机器、同一主题和字体缩放截图。
- 容器坐标、尺寸、分隔线误差不得超过 ±1px。
- 非文字区域颜色通道误差不得超过 4/255。
- 以 8/255 阈值比较时，非抗锯齿像素差异不得超过 0.5%。
- 字形抗锯齿可使用遮罩，但文本基线和包围盒仍须 ±1px。
- 终端和 Agent 两张基线图必须分别通过，不允许只验一张。

## 自适应

1600×1000 要求像素级一致；其他桌面尺寸要求结构一致、无横向溢出、输入框不遮挡内容、侧栏按现有 Warp 规则伸缩，不要求逐像素相同。
