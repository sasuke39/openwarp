## 评测（Terminal-Bench)

### 对照实验

- 基线：当前 sample9 / sample9-new / 77 题（无 todo 工具）
- 实验：加 todo 工具后的同样题目
- 变量：只有 todo 工具这一个

### 预期指标

| 指标 | 基线（无 todo) | 预期（有 todo) |
|---|---|---|
| sample9 通过率 | 5/9 | >5/9 |
| sample9-new 通过率 | 4/9 | >4/9 |
| path-tracing 类型（无限探索不产出） | 超时 | 提前完成或减少轮数 |
| cobol 类型（反复实验不产出） | 超时 | 提前完成或减少轮数 |
| db-wal 类型（走偏方向） | 超时 | 减少偏离轮数 |
| 平均每题轮数 | ~15 | 可能增加（多了 todo 调用），但总耗时应降 |

### 分析维度

跑完后从轨迹里提取：
- 每题 todo 总数和完成率
- 第一次调 update_task_list 在第几轮（越早越好）
- 有没有"标 completed 但没做对"的情况
- 有没有"全部 completed 但 reward=0"的情况

## 验收标准

1. 单测全过
2. 集成测试通过
3. sample9 和 sample9-new 重跑，通过率不低于基线
4. 至少一道之前超时的题（path-tracing / cobol / db-wal）提前完成或轮数减少
5. 没有引入新的崩溃或协议错误
