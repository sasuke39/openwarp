## 必过验收矩阵

| 场景 | 可观察通过标准 |
|---|---|
| echo / cd / Unicode / 多行 | 远端目录正确；输出无丢失、无截断；stderr 和非零退出码可见 |
| 非法 Shell 语法 | 执行前拒绝；终端未进入等待续行状态；下一命令正常 |
| foreground sleep | 等待期间保持运行态；不自动后台化；结束只回传一次 |
| background sleep | job_id 唯一；普通命令同时可执行；输出可轮询 |
| background 输入与取消 | 输入到指定任务；取消确认后远端任务结束；其他任务不受影响 |
| Stop 在生成/审批/执行/等待 | 请求可达；无永远 CANCELLING；迟到结果不污染下一轮 |
| Reject 后继续 | 框架收到拒绝；能正常完成并开始下一 Turn |
| 排队与 Steer | 默认不抢当前轮；按钮可见；下一 exchange 注入一次并保留用户输入 |
| 工具并发、超时与重复回包 | 所有 ID 有终态；不会无限等待、重复执行或提前恢复 |
| 上传与远端文件工具 | 中文/空格路径、内容哈希一致；不误传服务器；失败不报成功 |
| SSH 断线与 host key 变化 | 明确错误；不静默信任；不回退本机执行 |
| Harness/App 异常退出 | 历史可继续；旧运行中轮次标中断；无 running turn 永久锁定 |
| GUI | 真窗口输入、中文输入法、滚动、运行动画、停止按钮、上传拖放可用 |
| 安装与退出 | 普通用户可启动；无额外控制台闪窗；子进程按策略收尾 |
